# Project instructions

## Language

All project code and documentation must be written in English. This applies to
identifiers, comments, docstrings, test descriptions, user-facing text, error
messages, configuration descriptions, READMEs, specifications, development
notes, and saved prompts, including supporting files under `output/`.

Use English for all new or modified project text. Translate any existing
non-English code or documentation encountered during project work into English
without changing its meaning or behavior. Mathematical symbols and other
language-neutral notation are allowed.
